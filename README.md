# ResolumeLayerControl

An FFGL plugin for controlling a layer's Transition Blend Mode, Duration, and Mask Mode using an Effect Clip.

## Setup

1. Obtain the plugin DLL. Check [Releases](https://github.com/zukio/ResolumeLayerControl/releases) (no release has been published yet).
2. Copy the DLL to `%USERPROFILE%\Documents\Resolume Arena\Extra Effects`, or add its folder in Resolume preferences.
3. Start or restart **Resolume Arena**.
4. Open **Preferences > Webserver** and turn **Webserver ON**.
5. Create an empty Clip and add **Layer Ctrl Probe** to it as an Effect Clip.

Keep Webserver enabled while using the plugin.

> **Current status:** `Layer Ctrl Probe` is a diagnostic build. It does not yet change Layer Transition settings or Mask Mode.
